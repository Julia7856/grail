# 🏆 Grail: Руководство по установке и запуску

Добро пожаловать в Grail — вашу цифровую святыню. 
Это руководство поможет вам запустить систему защиты данных за 5 минут.

---

## 📋 Системные требования

- **Python:** версия 3.8 или выше ([Скачать Python](https://www.python.org/downloads/))
- **Операционная система:** Windows, macOS, Linux
- **Интернет:** не требуется (после установки)

---

## 🚀 Быстрый старт (для компьютера)

### Шаг 1: Скачайте проект
Нажмите зеленую кнопку **Code** на главной странице репозитория и выберите **Download ZIP**, либо клонируйте через терминал:
```bash
git clone https://github.com/Julia7856/grail.git
cd grail
```

### Шаг 2: Установите зависимости
Откройте терминал (или командную строку) в папке проекта и выполните:
```bash
pip install -r requirements.txt
```
*Это установит необходимые криптографические библиотеки и инструменты для работы с изображениями.*

### Шаг 3: Запустите Grail
Вы можете запустить проект в нескольких режимах:

**Полный конвейер защиты (все модули):**
```bash
python ultimate_grail.py
```

**Консольная версия (упрощенный тест):**
```bash
python main.py
```

**Графический интерфейс (красивое приложение):**
```bash
python gui.py
```

## 📱 Запуск на мобильном устройстве (Android)

1. Установите приложение **Pydroid 3** из Google Play.
2. Откройте Pydroid 3 → Меню (☰) → **Pip**.
3. Установите библиотеки по очереди:
   - Введите `cryptography` → **Install**
   - Введите `numpy` → **Install**
   - Введите `Pillow` → **Install**
4. Скопируйте код из файла `ultimate_grail.py` в редактор Pydroid.
5. Нажмите кнопку **Run** (▶).

## 🛡️ Как это работает?

1. **Regex-детектор** автоматически находит в вашем тексте личные данные (телефоны, email, паспорта, карты) из любой страны мира.
2. **Ядро Grail** шифрует текст с помощью AES-256-GCM (промышленный стандарт).
3. **Стеганография** скрывает зашифрованные данные внутри изображения.
4. **Blockchain Audit** записывает каждое действие в неизменяемый журнал.
5. **Self-Destruct** уничтожает ключи при попытке взлома.

**Roadmap v1.1:** постквантовое шифрование Kyber-1024 (стандарт NIST PQC).

## 🔧 Решение проблем

**Ошибка `ModuleNotFoundError: No module named 'cryptography'`**
→ Убедитесь, что вы выполнили `pip install -r requirements.txt`.

**Графический интерфейс не открывается**
→ Убедитесь, что у вас установлен Python с поддержкой Tkinter (на Linux: `sudo apt-get install python3-tk`).

**Ошибка при стеганографии**
→ Убедитесь, что установлены `numpy` и `Pillow`.
