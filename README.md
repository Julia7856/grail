# 🏆 Grail

**Ваша цифровая святыня. Неприкосновенная. Локальная. Вечная.** 🌍 English version: [README.en.md](README.en.md)

Grail — это инструмент защиты данных международного уровня. Regex-детектор находит личные данные, криптографическое ядро шифрует их, стеганография прячет внутри обычных картинок, а механизм самоуничтожения гарантирует, что ключи никогда не попадут в чужие руки.

---

## 🔑 Ключевые возможности

### 🔍 Regex-детектор PII (Personal Identifiable Information)

- Автоматически находит телефоны, email, паспорта, банковские карты, ИНН, СНИЛС, IP-адреса
- Поддержка международных форматов (РФ, США, ЕС, UK и др.)
- Работает локально, без отправки данных в интернет
- Валидация банковских карт по алгоритму Луна

### 🔒 Криптографическое ядро

- **AES-256-GCM** — промышленный стандарт шифрования (NIST)
- **Уникальный nonce для каждого сообщения** — защита от атак на GCM
- Полностью локальное шифрование, без облаков
- **Roadmap v1.1:** постквантовое шифрование Kyber-1024 (стандарт NIST PQC)

### 🖼️ Стеганография

- Прячет зашифрованные данные внутри обычных изображений (PNG, BMP)
- Метод LSB (Least Significant Bit) — данные невидимы для глаза
- **Честно:** LSB обнаруживается стегоанализом — это обфускация, а не абсолютная невидимость
- Конфиденциальность обеспечивает шифрование AES-256-GCM — стеганография лишь маскирует факт передачи
- Протокол с длиной сообщения (32-битный префикс)

### ⛓️ Blockchain Audit

- Неизменяемый журнал событий на основе цепочки хешей
- Любое изменение истории обнаруживается мгновенно
- **Честно:** это журнал целостности, а не распределённый блокчейн — он защищает от незаметных правок, а не от удаления файла

### 💥 Self-Destruct

- Безопасное стирание ключей и чувствительных данных
- Гарантирует, что ключи никогда не попадут в чужие руки
- **Честно:** на современных SSD полное стирание не всегда возможно — это минимизация риска, а не магия

## 📁 Структура проекта

- `core.py` — криптографическое ядро (двуязычные комментарии EN+RU)
- `ai_detector.py` — Regex-детектор PII + опциональный Presidio (ML)
- `steganography.py` — LSB-стеганография
- `blockchain_audit.py` — неизменяемый журнал
- `self_destruct.py` — механизм самоуничтожения
- `gui.py` — графический интерфейс
- `main.py` — консольный интерфейс
- `ultimate_grail.py` — полный рабочий процесс
