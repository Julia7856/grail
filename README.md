# 🏆 Grail

**Ваша цифровая святыня. Неприкосновенная. Локальная. Вечная.**
🌍 English version: [README.en.md](README.en.md)
Grail — это инструмент защиты данных международного уровня. Regex-детектор находит личные данные, криптографическое ядро шифрует их, стеганография прячет внутри обычных картинок, а механизм самоуничтожения гарантирует, что ключи никогда не попадут в чужие руки.

---

## 🔑 Ключевые возможности

### 🔍 Regex-детектор PII (Personal Identifiable Information)
- Автоматически находит телефоны, email, паспорта, банковские карты, ИНН, СНИЛС, IP-адреса
- Поддержка международных форматов (РФ, США, ЕС, UK и др.)
- Работает локально, без отправки данных в интернет
- Валидация банковских карт по алгоритму Луна

### 🔒 Криптографическое ядро
- **AES-256-GCM** — промышленный стандарт шифрования (NIST)
- **Уникальный nonce** для каждого сообщения — защита от атак на GCM
- Полностью локальное шифрование, без облаков
- **Roadmap v1.1:** постквантовое шифрование Kyber-1024 (стандарт NIST PQC)

### 🖼️ Стеганография
- Скрытие зашифрованных данных внутри обычных изображений (PNG, BMP)
- Метод LSB (Least Significant Bit) — данные невидимы для глаза
- Протокол с длиной сообщения (32-битный префикс)
- Идеально для передачи через открытые каналы (email, мессенджеры, соцсети)

### 🔗 Blockchain Audit
- Неизменяемый журнал всех действий с сохранением на диске
- Каждая запись защищена криптографически (SHA-256)
- Невозможно подделать историю операций
- Автоматическая верификация целостности цепочки

### 💣 Self-Destruct Mechanism
- Автоматическое уничтожение ключей при неудачных попытках доступа
- Уничтожение при длительном бездействии (настраиваемый таймаут)
- Ручная активация Emergency Destruct
- Перезапись ключей случайными данными (невозможно восстановить из RAM)

### 🎨 Графический интерфейс
- Красивое приложение с темной темой (изумрудно-бордовые тона)
- Простое управление: вставил текст → нажал кнопку → получил защиту
- Работает на Windows, macOS, Linux

## 🏗️ Архитектура проекта

**Полный цикл защиты:**
1. **Regex-детектор** находит личные данные
2. **Шифрование** (AES-256-GCM с уникальным nonce)
3. **Стеганография** (скрытие в изображении)
4. **Blockchain Audit** (запись в неизменяемый журнал)
5. **Self-Destruct** (вооружение системы самоуничтожения)

## 🚀 Быстрый старт

### Установка (подробнее в [INSTALL.md](INSTALL.md)):

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Julia7856/grail.git
cd grail

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите
python main.py              # Консольная версия
python gui.py               # Графический интерфейс
python ultimate_grail.py    # Полная демонстрация всех модулей
```

### Запуск на Android:
1. Установите **Pydroid 3** из Google Play
2. Меню → Pip → установите:
   - `cryptography`
   - `numpy`
   - `Pillow`
3. Скопируйте код из `ultimate_grail.py` и нажмите Run
