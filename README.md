
# 🏆 Grail

**Ваша цифровая святыня. Неприкосновенная. Локальная. Вечная.**

Grail — это инструмент абсолютной защиты данных международного уровня. AI-детектор находит личные данные, криптографическое ядро шифрует их, стеганография прячет внутри обычных картинок, а механизм самоуничтожения гарантирует, что ключи никогда не попадут в чужие руки.

---

##  Ключевые возможности

###  AI-детектор PII (Personal Identifiable Information)
- Автоматически находит телефоны, email, паспорта, банковские карты, ИНН, СНИЛС, IP-адреса
- Поддержка международных форматов (РФ, США, ЕС, UK и др.)
- Работает локально, без отправки данных в интернет
### 🔒 Криптографическое ядро


- **AES-256-GCM** — промышленный стандарт шифрования (NIST)
- **Уникальный nonce** для каждого сообщения — защита от атак на GCM
- Полностью локальное шифрование, без облаков
- **Roadmap v1.1:** постквантовое шифрование Kyber-1024 (стандарт NIST PQC)

### 🖼️ Стеганография
- Скрытие зашифрованных данных внутри обычных изображений (PNG, BMP)
- Метод LSB (Least Significant Bit) — данные невидимы для глаза
- Идеально для передачи через открытые каналы (email, мессенджеры, соцсети)

### 🔗 Blockchain Audit
- Неизменяемый журнал всех действий
- Каждая запись защищена криптографически
- Невозможно подделать историю операций

### 💣 Self-Destruct Mechanism
- Автоматическое уничтожение ключей при 3 неудачных попытках доступа
- Уничтожение при длительном бездействии (30 минут)
- Ручная активация Emergency Destruct
- Перезапись ключей случайными данными (невозможно восстановить из RAM)

###  Графический интерфейс
- Красивое приложение с темной темой (изумрудно-бордовые тона)
- Простое управление: вставил текст → нажал кнопку → получил защиту
- Работает на Windows, macOS, Linux

---

## Архитектура проекта

**Полный цикл защиты:**
1. AI находит личные данные → 2. Шифрует (AES-256-GCM) → 3. Прячет в картинку → 4. Записывает в Blockchain → 5. Вооружает Self-Destruct

## 🚀 Быстрый старт

### Установка (подробнее в [INSTALL.md](INSTALL.md)):

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Julia7856/grail.git
cd grail

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите
python main.py              # Консольная версия
python gui.py               # Графический интерфейс
python ultimate_grail.py    # Полная демонстрация
```

### Запуск на Android:
1. Установите **Pydroid 3** из Google Play
2. Меню → Pip → установите `cryptography` и `Pillow`
3. Скопируйте код из `main.py` и нажмите Run
